VetEngage's admin-facing panel for managing appointments, clients, and reports across multiple practice locations — scheduling, client tracking, and analytics in one place.

## What I worked on

- Built accessible, responsive dashboard interfaces with **React, Vite, TypeScript, and Tailwind CSS**, using the shared design system.
- Implemented views for scheduling across providers and locations, and client record management.
- Consumed the platform's **GraphQL API** for data fetching across dashboard views.
