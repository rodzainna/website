A shared React component library providing a consistent, accessible UI foundation across VetEngage's booking widget, admin dashboard, and marketing site.

## What I worked on

- Contributed reusable, accessible components built with **shadcn/ui and Tailwind CSS**.
- Used and extended the system's design tokens for consistent theming across apps.
- Documented components in **Storybook** for the rest of the team to consume.
