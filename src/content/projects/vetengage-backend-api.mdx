VetEngage's backend is a **FastAPI** service exposing a **GraphQL** API over **PostgreSQL**. As a full-stack contributor, I work across this layer as well as the frontend, rather than stopping at a handoff.

## What I worked on

- Contributed to GraphQL resolvers and schema supporting frontend features I was building.
- Worked with the team's **Docker**-based local dev environment for the API and database.
- Used `uv` for Python dependency and environment management.
