Luxsurance's admin dashboard — an enterprise-level insurtech tool for managing insurance operations, built with Vue.js and integrating a .NET backend.

## What I worked on

- Built client-facing dashboard features with **Vue.js and Tailwind CSS**.
- Owned frontend component architecture and state management for dashboard functionality.
- Integrated the **.NET REST API** for dashboard data.
- Continued frontend ownership through the product's acquisition by Jewelers Mutual, working in an Agile/Scrum delivery environment.
