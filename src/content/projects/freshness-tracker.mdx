A **Shopify** embedded app for stores that sell perishables. Merchants record each batch's quantity and expiry date on the product page, and a dashboard shows what's fresh, expiring soon or expired across the store.

It runs on a development store with 60 demo products; the README has screenshots and a demo GIF.

## What I built

- A product-page panel (Admin UI extension) to add, edit and remove batches, with live status badges and validation.
- A dashboard with search, filters, sorting and paging over Shopify's **Admin GraphQL API**, including an expiry sort Shopify can't do itself, and a CSV export of every batch.
- Fulfillment webhooks that use up the batch expiring first, skip expired stock and record any shortfall. The webhook replies at once and a job applies the change under a per-product lock, safe to retry.
- Batches stored in the merchant's own store as metaobjects; the app's database keeps only what processing needs, such as sessions, locks, jobs and shortfall records.
- 666 unit and integration tests, and a README that documents its limits.
