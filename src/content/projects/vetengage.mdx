VetEngage is the platform I currently work on as a Senior Frontend Developer (Full Stack). It serves multi-location veterinary practice groups with online booking, PIMS (practice information system) synchronization, and recall/reactivation workflows for clients.

## My role

I build client-facing features across a shared React design system, and contribute across the stack rather than stopping at the frontend:

- **Online Booking** — the embeddable, client-facing appointment-scheduling widget.
- **Admin Dashboard** — the internal panel practice staff use for scheduling, client tracking, and reports.
- **Marketing Website** — the public-facing site, sharing the same design system as the product apps.
- **Design System** — the shared shadcn/ui + Tailwind CSS component library every app is built on.
- **Backend** — Python/FastAPI services and GraphQL APIs, contributed to alongside frontend work.
